# korbat — Explore (2c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Readers find popular recent posts in an Explore tab ranked by a published formula; authors can keep their posts out and see why a post is or is not listed; nothing but a post's moderation state, its author's switch and the reader's own blocks and mutes takes a post out.

**Architecture:** Six commits: the ground (the contracts with EXPLORE_V1, migration 0011), the ranking (one bounded statement per refresh into a generations table, a job in the social module), the reads (the Explore page with its own cursor, the author's status, the switch, the author's chip), the web app (the tab, the list, the formula page, the switch, the status line), the fixes an adversarial review upheld, and the documentation.

**Tech Stack:** Node 24, TypeScript 7 (6 in the Expo app), Hono 4.13, zod 4, drizzle (an identity column and BRIN indexes), PostgreSQL 18, Valkey, Expo SDK 57 / expo-router, vitest 4.

**Complete code:** each task's full files, commands and observed output are in `docs/superpowers/prompts/explore-2c/NN-<slug>.md`, generated from a verified dry run. This plan is the map. Where it and a prompt differ, the prompt wins.

**Spec:** `docs/superpowers/specs/2026-09-28-explore-2c-design.md`.
