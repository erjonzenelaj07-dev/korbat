# korbat — Import from Other Platforms (3b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a person brings their own public posts from an X or Mastodon archive (Bluesky behind an owner switch, off by default): uploaded in resumable chunks to a quarantine volume never backed up, parsed by an importer service with no network, previewed post by post with the person's choices, published on an Imported tab of their profile only with a provenance label and never in anyone's feed, undone in one action, erased with the account, and ended as a whole by an admin from a case by a recorded decision.

**Architecture:** Eight commits, migrations 0043 to 0048: the contracts and the import protocol; the tables and their guards; the importer service with its own zip and CAR readers and three adapters; the API's imports module with the chunked upload and the scan; the preview's feeder, confirm and stop with the images through the matcher; publishing, the Imported tab, undo, the account's export and purge and the admin's end; the screens and the console's lines; and the record.

**Tech Stack:** Node 24 and Hono for the API and the importer (no network, read-only root, its own volume), cborg for Bluesky's CAR files, PostgreSQL 18 with drizzle migrations and row-level guards, Valkey, Docker Compose and Caddy with a chunk body limit; Expo SDK 57 for the web app and React 19 for the console; playwright-core 1.63 for both browser checks; vitest 4.

**Complete code:** each task's full files, commands and observed output are in `docs/superpowers/prompts/import-3b/NN-<slug>.md`, generated from a verified dry run. This plan is the map. Where it and a prompt differ, the prompt wins.

**Spec:** `docs/superpowers/specs/2026-10-22-import-3b-design.md`.
